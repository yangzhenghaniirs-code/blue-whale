# blue whale

DeepSeek Harness（DSH）插件：桌面上的 Live2D 桌宠「大肥鱼」，和 DSH 里你选的那个会话说话。角色的回复会带着表情、动作回到桌宠，由桌宠念出来。第一次打开桌宠就是大肥鱼，不用自己导入模型。

桌宠说的每句话，开头都带标签 `[from the blue whale]`。角色要知道「带这个标签的话该怎么回」（口语短句、写表情动作标记），所以**装好后要做一次**：
1. 第一次启动后，打开 `C:\Users\你的用户名\.dsh\blue-whale\贴进记忆的桌宠规则.txt`，全选复制。
2. 在 DSH 里把这段话发给你的角色，让它「记住这条规则」（或者贴进角色的人设 / 记忆）。

只做一次，以后每句话都很短，不占会话长度。不想改记忆的话，打开 DSH 左边「插件」→ 点 blue whale →「包含的组件」里把「**每句附上桌宠规则**」打开：每句话自动附上规则，装上就能用，代价是每句多三百字左右。随时可以开关，下一句就生效。

## 安装（在 DSH 里直接装）
1. 打开 DSH 设置 → 插件，搜索 `@yangzhenghan/dsh-bluewhale`（或 `bluewhale`），点安装。
2. 重启 DSH。
3. **第一次会自动下载桌宠程序**（约 485MB，只下一次；从旧版本更新也会重新下载一次新桌宠，旧的会自动删掉）：右下角会弹出「正在下载桌宠」的通知，下好、解压完桌宠会自己出来，站在屏幕右下角。网速快几分钟，慢的话要久一点，这期间 DSH 照常能用。
   - 先从 Gitee 下（国内不用梯子），不行再从 GitHub 下；下完会核对文件，下坏了不会装上。
   - 下载失败（比如断网）：重启 DSH 会接着下。

只支持 Windows。需要 DeepSeek Harness 桌面版，并且已经登录、在 DSH 窗口里能正常聊天。

> 杀毒软件（360 等）可能误删桌宠里的文件，导致桌宠没有托盘图标、角色被关在小框里。可以把 `C:\Users\你的用户名\.dsh\blue-whale` 加入信任。

## 手动安装（不想在线下载时）
到 [GitHub](https://github.com/yangzhenghaniirs-code/blue-whale/releases/tag/v0.4.1) 或 [Gitee](https://gitee.com/yangzhenghan/blue-whale/releases/tag/v0.4.1) 下载整包，解压后在 DSH 设置 → 插件 → 按本地路径安装。Gitee 的整包拆成了 6 份，合并方法看那边的说明。

## 模型
- 内置模型是「大肥鱼」，已经加好表情动作、换装动作、说话口型，是桌宠的初始模型，也是唯一自带的模型（AIRI 官方的示例模型已去掉）。
- 大肥鱼模型经原作者授权二次发布。模型的版权属于原作者，请不要单独拿出模型另作他用。

## 用法
- **拖动**：按住大肥拖动。只能在当前屏幕里拖，拖到别的屏幕会看不见，拖回来就好。
- **对桌宠说话**：右键桌宠，打开聊天或麦克风。
- **切换聊天**：右键桌宠 →「切换聊天」，会列出所有工作区里最近的会话，显示成「工作区名 · 会话标题」。选你平时和角色聊天的那个会话，桌宠就用那个角色的人设和记忆。
- **改表情规则**（0.4.0 起）：把插件里的 `桌宠规则.md` 复制到 `C:\Users\你的用户名\.dsh\blue-whale\桌宠规则.md` 再改，下一句话就生效；有这个文件就用它，插件更新也不会冲掉。
- **跳舞**（0.4.0 起）：右键大肥「动作 ▸ 跳舞」有三支：万圣节舞蹈、无名小舞蹈、比心小舞蹈；单击尾巴跳万圣节舞蹈。对她说「跳个舞」，她会回 `<|ACT {"motion":"跳舞"}|>`，桌宠随机跳一支（规则里已经写好；tag 模式要把新规则重新贴进角色记忆）。

## 设置（DSH 设置 → 插件 → blue whale）
| 设置 | 默认 | 说明 |
|---|---|---|
| `petTag` | `[from the blue whale]` | 桌宠消息开头的标签 |
| `ruleMode` | `tag` | `tag`：只带标签（规则要自己写进角色的记忆，见上面）；`prompt`：每句附上规则 |
| `allWorkspaces` | 开 | 切换聊天时列出所有工作区的会话 |
| `workDir` | `文档\deepseek-harness\blue whale` | 选「新建会话」时，新会话建在这里 |
| `autoDownloadPet` | 开 | 没有桌宠程序时自动下载 |
| `airiExe` | 自动 | 桌宠程序的位置，一般不用改 |
| `port` | 18100 | 桌宠连接的端口 |

## 要知道的
- **文件在哪**：自动下载的桌宠在 `C:\Users\你的用户名\.dsh\blue-whale\pet-版本号\`；日志 `dafei.log` 和当前会话 `state.json` 在 `C:\Users\你的用户名\.dsh\blue-whale\data\`。卸载插件后想彻底删掉，就把 `.dsh\blue-whale` 文件夹删了。
- **和 aurabot（QQ）一起用**：如果切换到 aurabot 建的 QQ 会话，对桌宠说的话的回复，aurabot 也会发到 QQ 上。
- **后续消息**：角色说完以后 1 分钟内补的话，比如提醒到点、主动搭话，桌宠也会念出来，一句一句地念。
- **屏幕边缘（0.3.3 起）**：鼠标在屏幕最边上按住拖，不会再拖到大肥（打开桌宠前插件自动修好）。
- **回到屏幕中心（0.4.1 起）**：右键托盘小图标点「回到屏幕中心」，大肥滑回所在屏幕正中（拖丢了、拖到边上找不到时用）。
- **托盘菜单（0.3.5 起）**：右键托盘小图标的「显示/隐藏桌宠」，桌宠开着时点它会隐藏，再点一次显示（左键单击小图标也能显示）。
- 用的是 18100 端口，别的程序占着这个端口时桌宠连不上。
- **国内用麦克风（0.3.1 起）**：桌宠判断「有没有人在说话」的语音检测模型原本要从 huggingface.co 下载，国内连不上，听力会卡在 Loading 或报 Failed to fetch。插件现在自带这个模型，在本机 18101 端口提供，并在打开桌宠前自动把桌宠里的下载地址改成本机。所以要从 DSH 里打开桌宠（不要单独打开 airi.exe），听力才能用。
