# blue whale

DeepSeek Harness（DSH）插件，**桌宠程序和 Live2D 模型「大肥鱼」都在里面**，下载解压这一个文件夹就能用，第一次打开桌宠就是大肥鱼，不用自己导入模型。它让桌面上的 Live2D 桌宠 blue whale 和 DSH 里你选的那个会话说话。角色的回复会带着表情、动作回到桌宠，由桌宠念出来。

桌宠说的每句话，开头都带标签 `[from the blue whale]`，后面还附上一段表情动作规则（`桌宠规则.md`，大约三百字）。你的人设和记忆**一个字都不用改**，装上就能用。代价是每句话多三百字左右，聊得越多，会话越长。

## 下载
安装包 `blue-whale-v0.3.0.zip`（约 470MB，桌宠程序和模型都在里面）：
- **GitHub**：https://github.com/yangzhenghaniirs-code/blue-whale/releases/tag/v0.3.0
- **国内（不用梯子）**：Gitee https://gitee.com/yangzhenghan/blue-whale/releases/tag/v0.3.0
  Gitee 单个文件不能太大，所以安装包拆成了 5 份：`blue-whale-v0.3.0.zip.001` 到 `.005`，**5 份都要下载**，放在同一个文件夹里，然后任选一种方法合起来：
  - 装了 7-Zip：右键 `.001` → 7-Zip → 解压，直接得到 `blue-whale` 文件夹。
  - 没装 7-Zip：在这个文件夹的地址栏输入 `cmd` 回车，运行 `copy /b blue-whale-v0.3.0.zip.001+blue-whale-v0.3.0.zip.002+blue-whale-v0.3.0.zip.003+blue-whale-v0.3.0.zip.004+blue-whale-v0.3.0.zip.005 blue-whale-v0.3.0.zip`，得到完整的 zip 再解压。

下载后解压，得到 `blue-whale` 文件夹，再按下面的步骤安装。

> 杀毒软件（360 等）可能误删桌宠里的文件，导致桌宠没有托盘图标、角色被关在小框里。解压前先把要放的文件夹加入信任。

## 里面有什么
```
blue-whale\
 ├─ index.js、src\、locale\ …   插件本体
 ├─ 桌宠\airi.exe …             桌宠程序，里面自带大肥鱼模型（插件会自动打开它，不用另外安装）
 └─ 桌宠规则.md                   表情动作规则
```

## 需要准备
- DeepSeek Harness 桌面版（已经登录，在 DSH 窗口里能正常聊天）

## 模型
- 内置模型是「大肥鱼」，已经加好表情动作、换装动作、说话口型，是桌宠的初始模型，也是唯一自带的模型（AIRI 官方的示例模型已去掉）。
- 大肥鱼模型经原作者授权二次发布。模型的版权属于原作者，请不要单独拿出模型另作他用。

## 安装
1. 把整个文件夹放到一个固定的位置，比如 `文档\blue-whale`，以后不要再挪（DSH 每次都从这里加载）。
2. 打开 DSH 设置 → 插件 → 按本地路径安装 → 选这个文件夹。
3. 重启 DSH，桌宠会自己出来，就是大肥鱼，站在屏幕右下角。

## 用法
- **拖动**：按住大肥拖动。只能在当前屏幕里拖，拖到别的屏幕会看不见，拖回来就好。
- **对桌宠说话**：右键桌宠，打开聊天或麦克风。
- **切换聊天**：右键桌宠 →「切换聊天」，会列出所有工作区里最近的会话，显示成「工作区名 · 会话标题」。选你平时和角色聊天的那个会话，桌宠就用那个角色的人设和记忆。
- **改表情规则**：直接改 `桌宠规则.md`。下一句话就生效，不用重启。

## 设置（DSH 设置 → 插件 → blue whale）
| 设置 | 默认 | 说明 |
|---|---|---|
| `petTag` | `[from the blue whale]` | 桌宠消息开头的标签 |
| `ruleMode` | `prompt` | `prompt`：每句附上规则；`tag`：只带标签（规则要自己写进角色的人设或记忆） |
| `allWorkspaces` | 开 | 切换聊天时列出所有工作区的会话 |
| `workDir` | `文档\deepseek-harness\blue whale` | 选「新建会话」时，新会话建在这里 |
| `airiExe` | 自带的 `桌宠\airi.exe` | 桌宠程序的位置，一般不用改 |
| `port` | 18100 | 桌宠连接的端口 |

## 要知道的
- **和 aurabot（QQ）一起用**：如果切换到 aurabot 建的 QQ 会话，对桌宠说的话的回复，aurabot 也会发到 QQ 上。
- **后续消息**：角色说完以后 1 分钟内补的话，比如提醒到点、主动搭话，桌宠也会念出来，一句一句地念。
- 用的是 18100 端口，别的程序占着这个端口时桌宠连不上。
- 日志在 `data\dafei.log`，当前用的会话记在 `data\state.json`。
- 改了插件代码要重启 DSH 才生效。
